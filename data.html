Data & files

Everything you need is in one starter folder: the data, the model outputs, and a plain app that already shows the right numbers.

Download the starter (.zip, 538 KB)

Prefer to browse? Every file is listed below and in the starter folder on GitHub. You can also see the plain starter running.

The three datasets

Real health data from the CDC's National Health and Nutrition Examination Survey (NHANES). One row is one person. These describe this survey sample, not the whole US population.

Every row is marked as training data ? (80%, what the models learned from) or validation data ? (20%, used to check them).

The five example people

Each dataset comes with five example people ?: real survey participants from the validation data, not students and not made up. Every app offers the same five, so reviewers can find the same example person in any app. They were picked to be interesting:

  • Example people 1–3: a low, a typical and a high outcome.
  • Example person 4: the one the forest's trees disagree on most.
  • Example person 5: the one the trees agree on most.

Their details are in people in each output file.

Using the model outputs

The three models were fitted once, on the training rows, and every number your app needs was saved to JSON ?. Don't retrain anything; read these files.

  • outputs/glucose.json, outputs/sbp.json, outputs/fev1.json: one file per dataset, with sections linear, forest and boosting.
  • SCHEMA.md 3 KB: the field guide.
  • check.md 2 KB: numbers your finished app must still show.
Example: load a dataset in the browser (Route A) 
import * as m10 from "./m10.js";

const bundle = await m10.loadBundle("sbp");      // "glucose", "sbp" or "fev1"
const person = bundle.people[0];                 // Example person 1
const ex = m10.linearExplain(bundle, person.values);
console.log(ex.baseline, ex.groupedPushes, ex.prediction);
console.log(bundle.forest.people[person.id].prediction);
Example: load a dataset in Python (Route B) 
import m10

bundle = m10.load_bundle("sbp")                  # "glucose", "sbp" or "fev1"
person = bundle["people"][0]                     # Example person 1
ex = m10.linear_explain(bundle, person["values"])
print(ex["baseline"], ex["grouped_pushes"], ex["prediction"])
print(bundle["boosting"]["best_validation_round"])
How were the models fitted?
  • Linear: LinearRegression() in natural units.
  • Forest: RandomForestRegressor(n_estimators=100, max_features="sqrt", bootstrap=True, random_state=0).
  • Boosting: GradientBoostingRegressor(loss="squared_error", n_estimators=500, learning_rate=0.1, max_depth=3, random_state=0).

All three use scikit-learn, fitted on the same training rows (a fixed 80/20 split, seed 0). manifest.json 3 KB records the versions and row counts.

Rebuild the data yourself

Everything in the starter's data/ and outputs/ folders can be rebuilt from the original NHANES files with one command. See the reproduce folder on GitHub:

pip install -r reproduce/requirements.txt
python reproduce/reproduce.py --check

The script downloads the eight NHANES files from the CDC and checks each against a recorded SHA-256 fingerprint. It then rebuilds the three CSVs and refits the three models with pinned package versions. With --check, it confirms the rebuilt files match the ones you downloaded.
