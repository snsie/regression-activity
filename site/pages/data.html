The three datasets

Real health data from the CDC's National Health and Nutrition Examination Survey (NHANES). One row is one person. These describe this survey sample, not the whole US population.

Every row is marked as training data {{help training-data}} (80%, what the models learned from) or validation data {{help validation-data}} (20%, used to check them).

Fasting glucose

2,397 adults from NHANES 2017–2018 who fasted before their blood test. Age 80 means 80 or older. {{dl data/glucose.csv}}

{{dataset glucose}}

Blood pressure

4,370 adults from NHANES 2017–2018. Race/ethnicity is stored as five 0/1 columns; all zeros means Non-Hispanic White, the reference group {{help reference-group}}. These are associations in the data, not biological effects. {{dl data/sbp.csv}}

{{dataset sbp}}

Lung function (FEV₁)

5,820 people aged 6–79 from NHANES 2011–2012, the most recent survey with lung tests. Height is left out on purpose, so the models have to learn how lung size changes with age. {{dl data/fev1.csv}}

{{dataset fev1}}

The five people

Every app uses the same five validation people per dataset, so reviewers can compare apps. They were picked to be interesting:

  • Persons 1–3: a low, a typical and a high outcome.
  • Person 4: the one the forest's trees disagree on most.
  • Person 5: the one the trees agree on most.

Their details are in people in each output file.

Using the model outputs

The three models were fitted once, on the training rows, and every number your app needs was saved to JSON {{help model-outputs}}. Don't retrain anything; read these files.

  • outputs/glucose.json, outputs/sbp.json, outputs/fev1.json: one file per dataset, with sections linear, forest and boosting.
  • {{dl outputs/SCHEMA.md}}: the field guide.
  • {{dl check.md}}: numbers your finished app must still show.
Example: load a dataset in the browser (Route A) 
import * as m10 from "./m10.js";

const bundle = await m10.loadBundle("sbp");      // "glucose", "sbp" or "fev1"
const person = bundle.people[0];                 // Person 1
const ex = m10.linearExplain(bundle, person.values);
console.log(ex.baseline, ex.groupedPushes, ex.prediction);
console.log(bundle.forest.people[person.id].prediction);
Example: load a dataset in Python (Route B) 
import m10

bundle = m10.load_bundle("sbp")                  # "glucose", "sbp" or "fev1"
person = bundle["people"][0]                     # Person 1
ex = m10.linear_explain(bundle, person["values"])
print(ex["baseline"], ex["grouped_pushes"], ex["prediction"])
print(bundle["boosting"]["best_validation_round"])
How were the models fitted?
  • Linear: LinearRegression() in natural units.
  • Forest: RandomForestRegressor(n_estimators=100, max_features="sqrt", bootstrap=True, random_state=0).
  • Boosting: GradientBoostingRegressor(loss="squared_error", n_estimators=500, learning_rate=0.1, max_depth=3, random_state=0).

All three use scikit-learn, fitted on the same training rows (a fixed 80/20 split, seed 0). {{dl data/manifest.json}} records the versions and row counts.
